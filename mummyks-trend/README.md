# MummyK's Trend shop

Shop site (index.html) and admin page (admin.html) for MummyK's Trend.

- Hosting: Cloudflare Worker "mummyks-trend" built from this repo with root directory `mummyks-trend`.
- Database: the same Supabase project as Hottest Gist. Run `setup-shop.sql` once, then add admin emails to `shop_admins`.
- Admin: open /admin.html, create a password with an admin email, then add products, see orders, VIP list and shop settings.
